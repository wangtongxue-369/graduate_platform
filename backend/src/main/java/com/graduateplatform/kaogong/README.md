# 考公模块测试流程说明

本文档用于帮助测试人员按业务流程测试考公模块。测试重点不是单独验证接口字段，而是验证普通用户和管理员在页面中的完整使用链路是否正常。

## 1. 测试角色

### 普通用户

普通用户用于测试考公前台功能，包括：

- 查看考公首页。
- 查询岗位。
- 收藏和取消收藏岗位。
- 查询进面分数线。
- 收藏和取消收藏分数线。
- 查看考试日历。
- 订阅和取消订阅考试提醒。
- 创建模拟面试房间。
- 加入模拟面试房间。
- 在房间讨论区发送消息。
- 上传和下载附件。
- 查看和提交复盘评价。
- 结束自己创建的房间。

### 管理员

管理员用于测试后台考公数据维护功能，包括：

- 新增、编辑、下架考公岗位。
- 新增、编辑、下架进面分数线。
- 新增、编辑、下架考试日历节点。
- 验证后台维护后的数据能否在用户端正常展示。

## 2. 测试前准备

1. 启动后端服务。
2. 启动前端服务。
3. 确认数据库连接正常。
4. 准备至少一个普通用户账号和一个管理员账号。
5. 普通用户必须使用真实账号登录，不能使用前端 DevBar 的模拟用户进行收藏、订阅、创建房间、发消息或上传附件。

## 3. 用户端测试流程

### 3.1 登录并进入考公首页

操作步骤：

1. 使用普通用户账号登录系统。
2. 进入考公模块首页。
3. 查看首页是否展示考公相关功能入口。

预期结果：

- 能正常进入考公首页。
- 页面能看到岗位、考试日历、进面分数线、模拟面试等入口。
- 如果用户已有收藏、订阅或房间消息，首页应展示对应信息。

### 3.2 岗位查询、收藏和取消收藏

操作步骤：

1. 进入岗位查询或岗位匹配页面。
2. 使用地区、考试类型、年份、岗位名称等条件进行筛选。
3. 点击某个岗位的收藏按钮。
4. 返回首页或收藏列表查看该岗位。
5. 再次点击已收藏按钮，取消收藏。

预期结果：

- 岗位列表能正常分页展示。
- 筛选条件生效。
- 点击收藏后，按钮状态变为已收藏。
- 首页或收藏列表中能看到该岗位。
- 再次点击后可以取消收藏，状态恢复为未收藏。

### 3.3 进面分数线查询、收藏和取消收藏

操作步骤：

1. 进入进面分数线页面。
2. 根据地区、年份、考试类型、岗位名称等条件查询。
3. 收藏一条分数线。
4. 返回首页查看收藏分数线展示。
5. 取消收藏该分数线。

预期结果：

- 分数线列表能正常分页展示。
- 查询条件生效。
- 收藏后状态变为已收藏。
- 首页能展示用户收藏的进面分数线。
- 取消收藏后首页不再展示该收藏记录。

### 3.4 考试日历、考试订阅和取消订阅

操作步骤：

1. 进入考试日历页面。
2. 查看考试节点列表。
3. 使用节点筛选功能筛选不同考试或地区。
4. 订阅某一场考试。
5. 返回考公首页查看考试倒计时提醒。
6. 回到考试日历或订阅管理区域取消订阅。

预期结果：

- 考试节点能正常展示。
- 节点筛选功能生效。
- 同一场考试下的公告发布、报名、缴费、准考证打印等节点应聚合为一场考试提醒。
- 订阅某一场考试后，只应该该考试显示已订阅，不应全部考试都变为已订阅。
- 首页能展示订阅考试的下一节点和倒计时。
- 取消订阅后，首页不再展示该考试提醒。

### 3.5 创建模拟面试房间

操作步骤：

1. 进入模拟面试页面。
2. 点击创建房间。
3. 填写房间标题、岗位方向、面试时间、房间描述等信息。
4. 提交创建。

预期结果：

- 房间创建成功。
- 创建后自动进入该房间的讨论区。
- 当前用户成为房主。
- 房主能看到结束房间按钮。

### 3.6 加入模拟面试房间

操作步骤：

1. 使用另一个普通用户账号登录。
2. 进入模拟面试页面。
3. 点击加入房间。
4. 使用标题、方向、状态、时间等条件筛选房间。
5. 选择一个未结束的房间加入。

预期结果：

- 房间列表能正常分页展示。
- 筛选条件生效。
- 未结束房间可以加入。
- 已结束房间不能加入。
- 加入后自动进入房间讨论区。

### 3.7 房间讨论区发送消息

操作步骤：

1. 进入已加入的面试房间讨论区。
2. 在底部输入框输入消息。
3. 点击发送。
4. 使用另一个用户账号进入同一房间查看消息。

预期结果：

- 消息发送成功。
- 发送后输入框清空。
- 消息显示在讨论区中。
- 自己发送的消息靠右显示，其他用户消息靠左显示。
- 页面刷新后消息记录仍然存在。
- 房间消息支持分页查看。

### 3.8 房间附件上传和下载

操作步骤：

1. 在房间讨论区点击输入框旁边的上传图标。
2. 选择 Word、PDF、图片、音频或压缩包等附件。
3. 等待上传完成。
4. 在附件列表中点击下载。

预期结果：

- 上传入口显示为聊天窗口中的小图标。
- 上传过程中能看到上传进度。
- 上传成功后附件出现在附件列表中。
- 附件可以被下载。
- 单个附件超过限制时应提示上传失败。
- 不支持的文件类型应提示上传失败。
- 房间结束后不能继续上传附件。

### 3.9 房间复盘评价

操作步骤：

1. 在房间讨论区点击复盘评价入口。
2. 进入该房间的复盘评价区域。
3. 填写总分、表达、逻辑、礼仪、亮点、问题和建议。
4. 提交评价。
5. 返回房间查看精华复盘评价或评价列表。

预期结果：

- 能正常进入复盘评价区域。
- 评价提交成功。
- 新提交的评价能在评价列表中展示。
- 评价列表支持分页。
- 房间讨论区能展示部分精华复盘评价入口。

### 3.10 结束房间

操作步骤：

1. 使用房主账号进入自己创建的房间。
2. 点击结束房间。
3. 再尝试发送消息或上传附件。
4. 使用其他用户尝试加入该房间。

预期结果：

- 只有房主能结束房间。
- 结束后房间状态变为已结束。
- 已结束房间不能继续发送消息。
- 已结束房间不能继续上传附件。
- 已结束房间不能再被新用户加入。
- 已结束房间仍可查看历史消息、附件和复盘评价。

## 4. 管理端测试流程

### 4.1 岗位数据维护

操作步骤：

1. 使用管理员账号登录后台。
2. 进入考公数据管理页面。
3. 新增一条岗位数据。
4. 编辑该岗位数据。
5. 在用户端岗位页面查询该岗位。
6. 管理员下架该岗位。
7. 再次在用户端查询该岗位。

预期结果：

- 管理员可以新增岗位。
- 管理员可以编辑岗位。
- 新增或编辑后的岗位能在用户端正常展示。
- 下架后，用户端不再展示该岗位。
- 管理端仍可查询到该记录，用于后续维护。

重点检查字段：

- 考试类型。
- 年份。
- 地区。
- 岗位名称。
- 招录单位。
- 招录人数。
- 学历要求。
- 专业要求。
- 报名开始和结束时间。

### 4.2 进面分数线维护

操作步骤：

1. 管理员进入进面分数线管理区域。
2. 新增一条分数线数据。
3. 编辑该分数线数据。
4. 在用户端进面分数线页面查询。
5. 用户收藏该分数线。
6. 管理员下架该分数线。
7. 用户端再次查询。

预期结果：

- 管理员可以新增和编辑分数线。
- 用户端能查询到有效分数线。
- 用户可以收藏分数线。
- 下架后，用户端不再展示该分数线。

重点检查字段：

- 地区。
- 年份。
- 考试类型。
- 岗位名称。
- 招录单位。
- 进面分数线。
- 面试比例。
- 招录人数。
- 进面人数。

### 4.3 考试日历节点维护

操作步骤：

1. 管理员进入考试日历节点管理区域。
2. 新增某场考试的多个节点，例如公告发布、报名开始、报名截止、缴费截止、准考证打印。
3. 用户端进入考试日历页面查看。
4. 用户订阅该考试。
5. 管理员编辑其中一个节点日期或说明。
6. 用户端再次查看首页提醒。
7. 管理员下架某个节点。

预期结果：

- 管理员可以新增、编辑和下架考试节点。
- 用户端能按考试聚合展示节点。
- 用户订阅考试后，首页能展示该考试的下一节点提醒。
- 节点日期或说明修改后，用户端展示同步更新。
- 下架节点后，用户端不再展示该节点。

重点检查字段：

- 地区。
- 考试类型。
- 年份。
- 节点类型。
- 节点标题。
- 节点日期。
- 节点说明。

## 5. 重点回归测试项

每次修改考公模块后，建议重点回归以下内容：

1. 登录真实用户后，收藏岗位是否正常。
2. 岗位取消收藏后，首页是否同步消失。
3. 分数线收藏和取消收藏是否正常。
4. 订阅某一场考试时，是否只有该考试变为已订阅。
5. 取消订阅后，首页考试提醒是否消失。
6. 考试节点是否按考试聚合展示。
7. 创建房间后是否能进入讨论区。
8. 加入房间筛选功能是否生效。
9. 房间消息是否能发送和分页查看。
10. 附件是否能上传、显示进度和下载。
11. 房间结束后是否禁止发消息和上传附件。
12. 复盘评价是否能提交和分页查看。
13. 管理员新增的数据是否能在用户端展示。
14. 管理员下架的数据是否从用户端隐藏。

## 6. 常见问题排查

### 提示需要真实账号登录

原因：

- 当前使用的是 DevBar 模拟用户。
- 或 JWT 已过期。

处理方式：

- 退出当前账号后重新使用真实账号登录。
- 不要用 DevBar 模拟用户测试收藏、订阅、发消息和上传附件。

### 点击收藏、订阅、创建房间没有效果

检查项：

- 浏览器是否登录真实用户。
- 请求是否携带 `Authorization: Bearer <token>`。
- 后端服务是否正常启动。
- 数据库连接是否正常。

### 房间显示正在重连

原因：

- 房间实时通信使用 SSE。
- 后端未启动或连接中断时，前端会显示正在重连。

处理方式：

- 确认后端服务运行正常。
- 刷新页面重新进入房间。

### 附件上传失败

检查项：

- 文件大小是否超过 30MB。
- 文件类型是否在允许范围内。
- 房间是否已经结束。
- 当前用户是否真实登录。
- 后端上传目录是否有写入权限。

## 7. 测试通过标准

测试通过需要满足以下条件：

- 普通用户能完整走通岗位、分数线、考试订阅和模拟面试房间流程。
- 管理员能维护岗位、分数线和考试节点。
- 管理员维护的数据能正确影响用户端展示。
- 收藏、取消收藏、订阅、取消订阅等状态切换正确。
- 分页、筛选、上传、下载、复盘评价等交互正常。
- 未登录或模拟用户不能执行需要真实身份的操作。
