# 留学模块功能说明与使用路径

本文档用于说明“毕业去向导航与交流平台”中留学模块的功能范围、普通用户使用路径、管理员相关路径和后续测试用例拆分依据。留学模块主要面向准备出国留学的学生，帮助用户管理目标院校申请、申请时间线、材料清单和留学经验内容。

## 1. 模块入口

前端页面入口：

| 功能 | 路由 | 说明 |
| --- | --- | --- |
| 留学工作台 | `/studyabroad` | 留学模块首页，展示申请项目概览、材料完成率、时间线完成率和截止提醒 |
| 申请项目 | `/studyabroad/applications` | 管理目标院校、专业、申请轮次、截止日期、状态和梯度 |
| 申请时间线 | `/studyabroad/timeline` | 管理语言考试、文书、网申、面试、签证等节点 |
| 材料清单 | `/studyabroad/materials` | 管理申请材料，并支持材料附件上传、下载、删除 |
| 经验库 | `/studyabroad/experience` | 浏览公开留学经验，登录后发布、编辑、删除自己的经验 |
| 经验库别名 | `/studyabroad/experiences` | 指向同一个经验库页面，避免用户访问复数路径时无法进入 |
| 留学社区 | `/community?category=liuxue` | 与社区模块合并，用于留学相关讨论帖 |

导航栏路径：

1. 打开网站首页。
2. 鼠标移动或点击顶部导航中的“留学专属”。
3. 可进入“申请项目”“申请时间线”“材料清单”“经验库”“留学社区（并入）”。

## 2. 普通用户使用路径

### 2.1 游客访问

游客没有登录时，可以使用以下能力：

1. 进入 `/studyabroad` 查看留学模块示例说明和登录引导。
2. 进入 `/studyabroad/experience` 浏览公开留学经验。
3. 使用经验库筛选条件，例如国家/地区、主题、关键词。
4. 进入 `/community?category=liuxue` 浏览留学社区公开内容。

游客不能使用以下能力：

1. 不能创建、编辑、删除申请项目。
2. 不能创建、编辑、删除时间线事项。
3. 不能创建、编辑、删除材料清单。
4. 不能上传、下载、删除个人材料附件。
5. 不能发布、编辑、删除留学经验。

### 2.2 登录用户核心流程

推荐的完整使用流程如下：

1. 登录账号。
2. 进入 `/studyabroad` 留学工作台。
3. 点击“管理申请项目”，进入 `/studyabroad/applications`。
4. 新增目标申请项目，例如国家、学校、专业、学位、入学季、申请轮次、截止日期、申请状态、申请梯度和备注。
5. 进入 `/studyabroad/timeline`，为申请项目创建时间线节点，例如语言考试、文书初稿、推荐信、网申提交、面试、签证。
6. 进入 `/studyabroad/materials`，为申请项目创建材料条目，例如成绩单、个人陈述、推荐信、语言成绩、简历、护照。
7. 在材料条目中上传附件，上传后可查看附件列表，并进行下载或删除。
8. 回到 `/studyabroad` 工作台，查看项目概览、材料完成率、时间线完成率、7 天内截止提醒和逾期提醒。
9. 进入 `/studyabroad/experience`，浏览其他同学公开经验。
10. 发布自己的留学经验，填写标题、国家/地区、主题、作者名、阅读时长、摘要、正文和标签。
11. 对自己发布的经验进行编辑或删除。

### 2.3 申请项目管理

页面路径：`/studyabroad/applications`

主要功能：

1. 查看当前登录用户自己的申请项目列表。
2. 新增申请项目。
3. 编辑申请项目。
4. 删除申请项目。
5. 按申请状态、申请梯度、国家/地区等信息辅助查看。

关键字段：

| 字段 | 说明 |
| --- | --- |
| 国家/地区 | 申请目的地，例如英国、美国、加拿大等 |
| 学校 | 目标院校名称 |
| 专业 | 目标专业名称 |
| 学位 | 本科、硕士、博士等 |
| 入学季 | 例如 2027 Fall |
| 申请轮次 | Round 1、Round 2 等 |
| 截止日期 | 用于工作台截止提醒 |
| 申请状态 | 规划中、准备中、已提交、已录取、已拒绝等 |
| 申请梯度 | 冲刺、匹配、保底 |
| 备注 | 记录补充说明 |

数据权限：

1. 用户只能查看自己的申请项目。
2. 用户只能编辑或删除自己的申请项目。
3. 删除申请项目时，会清理该项目关联的时间线和材料数据，避免产生孤立记录。

### 2.4 申请时间线管理

页面路径：`/studyabroad/timeline`

主要功能：

1. 查看当前登录用户自己的时间线事项。
2. 新增时间线事项。
3. 编辑时间线事项。
4. 删除时间线事项。
5. 按截止日期和完成状态辅助查看。

关键字段：

| 字段 | 说明 |
| --- | --- |
| 关联申请项目 | 可关联某个申请项目，也可以作为通用事项 |
| 标题 | 例如“提交网申”“完成 PS 初稿” |
| 国家/地区 | 所属申请目的地 |
| 学校 | 所属学校，没有明确学校时可显示待定院校 |
| 阶段 | 语言考试、文书、网申、面试、签证等 |
| 截止日期 | 用于工作台截止提醒 |
| 状态 | 待办、进行中、已完成 |
| 备注 | 记录补充说明 |

数据权限：

1. 用户只能查看自己的时间线事项。
2. 用户只能编辑或删除自己的时间线事项。
3. 时间线只能关联当前用户自己的申请项目。

### 2.5 材料清单与附件管理

页面路径：`/studyabroad/materials`

主要功能：

1. 查看当前登录用户自己的材料清单。
2. 新增材料条目。
3. 编辑材料条目。
4. 删除材料条目。
5. 标记材料是否完成。
6. 为材料上传附件。
7. 下载材料附件。
8. 删除材料附件。

关键字段：

| 字段 | 说明 |
| --- | --- |
| 关联申请项目 | 可关联某个申请项目，也可以作为通用材料 |
| 材料名称 | 例如个人陈述、成绩单、推荐信、简历 |
| 国家/地区 | 所属申请目的地 |
| 阶段 | 文书、网申、签证等 |
| 类别 | 材料分类 |
| 截止日期 | 用于工作台截止提醒 |
| 是否完成 | 用于计算材料完成率 |
| 备注 | 记录补充说明 |

附件规则：

1. 每个材料最多上传 5 个附件。
2. 单个附件最大 10MB。
3. 附件通过后端上传到对象存储。
4. 附件下载必须登录，并且只能下载自己的材料附件。
5. 附件删除必须登录，并且只能删除自己的材料附件。

数据权限：

1. 用户只能查看自己的材料条目。
2. 用户只能编辑或删除自己的材料条目。
3. 用户只能操作自己材料下的附件。
4. 他人材料附件下载、删除会返回无权限错误。

### 2.6 留学经验库

页面路径：`/studyabroad/experience`

主要功能：

1. 游客和登录用户都可以浏览公开经验。
2. 支持分页浏览。
3. 支持国家/地区筛选。
4. 支持主题筛选。
5. 支持关键词搜索，并带有前端防抖，减少频繁请求。
6. 登录用户可以发布经验。
7. 作者可以编辑自己的经验。
8. 作者可以删除自己的经验。
9. 非作者不会看到编辑和删除按钮。

经验文章字段：

| 字段 | 说明 |
| --- | --- |
| 标题 | 经验文章标题 |
| 国家/地区 | 经验所属目的地 |
| 主题 | 选校定位、申请流程、语言考试、PS 文书、签证、海外生活等 |
| 作者名 | 前台展示的作者名称 |
| 阅读时长 | 例如 5 min |
| 摘要 | 列表卡片展示摘要 |
| 正文 | 编辑表单中维护正文，列表页不直接展示全文 |
| 标签 | 用于补充分类和关键词 |

权限规则：

1. `GET /api/studyabroad/experiences` 公开。
2. `GET /api/studyabroad/experiences/page` 公开。
3. `POST /api/studyabroad/experiences` 需要登录。
4. `PUT /api/studyabroad/experiences/{id}` 需要登录，并且只能作者本人操作。
5. `DELETE /api/studyabroad/experiences/{id}` 需要登录，并且只能作者本人操作。

### 2.7 留学工作台

页面路径：`/studyabroad`

工作台用于汇总用户的留学数据，帮助用户优先处理紧急事项。

展示内容：

1. 申请项目数量。
2. 材料完成率。
3. 7 天内截止事项数量。
4. 已逾期事项数量。
5. 时间线完成进度。
6. 材料清单完成进度。
7. 项目概览。
8. 截止提醒列表。
9. 进入申请项目、时间线、材料清单、经验库的功能卡片。

截止提醒来源：

1. 申请项目截止日期。
2. 未完成时间线事项截止日期。
3. 未完成材料条目截止日期。

## 3. 管理员相关路径

### 3.1 当前已存在的管理员路径

系统已有通用管理员后台入口：

| 功能 | 路由 | 与留学模块关系 |
| --- | --- | --- |
| 管理员首页 | `/admin` | 通用后台首页，不是留学专属后台 |
| 帖子审核 | `/admin/review` | 可用于处理社区帖子；留学社区内容如果以社区帖形式发布，可走社区审核逻辑 |
| 用户管理 | `/admin/users` | 可管理平台用户账号状态 |
| 举报处理 | `/admin/reports` | 可处理社区举报 |

留学社区入口 `/community?category=liuxue` 属于社区模块。如果用户在留学社区发帖，管理员可以按社区模块已有后台能力进行审核、处理举报、管理用户。

### 3.2 当前没有的留学专属管理员功能

截至本文档编写时，留学模块没有独立的留学管理员后台页面，也没有 `/api/admin/studyabroad/**` 形式的留学专属后台接口。

因此以下功能目前不属于已完成功能，不能作为已实现测试用例编写：

1. 管理员审核留学经验文章。
2. 管理员下架留学经验文章。
3. 管理员查看所有用户的留学申请项目。
4. 管理员查看所有用户的留学材料附件。
5. 管理员统计留学申请数据。
6. 管理员维护院校库、专业库、申请模板库。

这些内容可以写入答辩中的“后续优化方向”，但不建议写成当前版本已经完成的功能。

## 6. 当前版本边界

已经完成的核心能力：

1. 普通用户留学申请项目管理。
2. 普通用户时间线管理。
3. 普通用户材料清单管理。
4. 材料附件上传、下载、删除。
5. 公开经验库浏览。
6. 登录用户发布、编辑、删除自己的经验。
7. 工作台统计和截止提醒。
8. 个人数据权限控制。
9. 常见错误提示中文化。

当前未实现但可作为后续优化的能力：

1. 留学专属管理员后台。
2. 留学经验审核和下架。
3. 截止日期主动通知，例如站内通知或邮件提醒。
4. 语言成绩管理，例如雅思、托福、GRE、GMAT。
5. 经验文章点赞、收藏、评论。
6. 申请详情页。
7. 院校库、专业库、材料模板库。

## 7. 答辩时可概括的功能闭环

本模块的普通用户闭环可以这样说明：

1. 用户先创建目标申请项目。
2. 再为项目拆分时间线节点。
3. 同时维护材料清单和附件。
4. 工作台自动汇总项目进度、材料完成率和截止提醒。
5. 用户可以在经验库浏览公开经验，也可以发布自己的申请复盘。
6. 所有个人申请、时间线、材料和附件都做了登录和本人权限校验。

管理员闭环可以这样说明：

1. 当前系统已有通用管理员后台，能处理用户管理、社区审核、举报等平台级事务。
2. 留学社区内容并入社区模块，可走社区后台管理逻辑。
3. 留学经验库目前是公开浏览和作者自管理，尚未实现留学专属审核后台。
4. 留学专属管理员功能会作为后续扩展方向。
